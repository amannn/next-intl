# @eloqnt/extractor

Extracts messages from source code, shared by [next-intl](https://next-intl.dev) and the [eloqnt CLI](https://cli.eloqnt.dev).

**For internal use only.** This package has no public API: everything is exported from `_internal` entry points that can change in any release, including patches. Depend on `next-intl` or `@eloqnt/cli` instead.
